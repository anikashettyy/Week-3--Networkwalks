# NetworkWalks Internship – PM1 & PM2

This repository documents two hands-on exercises completed as part of my cybersecurity internship with NetworkWalks, focusing on password security and password hash analysis.

## PM1 – Password Cracking using John the Ripper

Explored password-cracking techniques using John the Ripper (JtR), a password auditing tool used to test password hashes.

### Objectives
- Understand the fundamentals of password hashing.
- Explore password-cracking techniques using John the Ripper.
- Observe how weak passwords may be recovered from hashes.
- Understand the importance of strong passwords and secure authentication practices.

### Tool Used
- John the Ripper (JtR)

## PM2 – Hash Analysis using NetworkWalks Hash Calculator

Performed a practical exercise using the Hash Calculator tool available on the NetworkWalks website to explore password hashes and their relationship to plaintext input.

### Objectives
- Understand the concept of hashing.
- Generate and explore hash values using the NetworkWalks Hash Calculator.
- Understand how hashing transforms input into hash values.
- Explore password security and the role of hashes in authentication systems.

### Tool Used
- NetworkWalks Hash Calculator (Website)

## Key Learning Outcomes
- Understanding the fundamentals of password hashing.
- Exposure to password-cracking techniques.
- Familiarity with John the Ripper.
- Understanding hash generation and password security.
- Awareness of the importance of strong passwords and secure authentication.

This repository contains lab screenshots, documentation, observations and the work completed during PM1 and PM2.
